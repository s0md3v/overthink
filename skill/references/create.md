# Create

## Core move

Expand the option space before choosing. Generate structurally different branches, not many surface variants.

Creativity is useful movement across representations, constraints, analogies, objectives, actors, scales, and forms. It is not randomness.

## Generate branches

Choose operators that attack different parts of the box. Protect weak or strange ideas long enough to extract their useful mechanism. If an operator fundamentally reframes the problem (e.g., objective editing, constraint editing), step back and run `model` to lock in the new frame before continuing.

- Redescription: rewrite the task with different nouns, verbs, units, boundaries, or causal direction. Ask what the wrong noun is.
- Abstraction: strip surface detail; keep the relation, function, tension, or pattern; solve there and map back.
- Decomposition: split by parts, stages, actors, incentives, interfaces, failure modes, feedback loops, or hidden dependencies.
- Recombination: fuse mechanisms, metaphors, genres, constraints, or tools usually kept apart.
- Analogy: map roles and causal links from another domain, not surface traits.
- Inversion: ask how to cause failure, intensify the problem, or produce the opposite effect; reverse what survives.
- Constraint editing: remove, weaken, delay, invert, outsource, automate, or make explicit one constraint.
- Objective editing: ask whether the metric is a proxy; try nearby aims such as resilience, truth, beauty, learning, optionality, or reduced harm.
- Boundary search: examine extremes, degenerate cases, smallest cases, largest cases, first cases, and last cases.
- Temporal shift: move the intervention earlier, later, continuously, periodically, or after failure.
- Scale shift: imagine the problem much smaller and much larger; note which assumptions change.
- Agent shift: view the task from another actor: novice, expert, maintainer, adversary, customer, critic, future self, or the system itself.
- Form shift: for aesthetic or communicative tasks, change medium, voice, genre, rhythm, metaphor system, viewpoint, or rule set.
- Counterfactual: ask what changes if a key assumption is false; ask what world makes a bad idea good or a good idea fail.
- Subtraction: remove components instead of adding them; ask what can become unnecessary, invisible, automatic, self-enforcing, or impossible to misuse.
- Latent-variable search: look for hidden causes, incentives, bottlenecks, definitions, dependencies, or emotional/aesthetic drivers.
- Contrarian probe: consider the opposite only when there is a plausible reason the default view may be wrong.

## Failure checks

Watch for:

- producing many variants of one idea
- novelty unrelated to the goal
- rejecting strange ideas before extracting their useful mechanism
- forced contrarianism
- adding complexity when subtraction may work
- polishing the first frame instead of replacing it
- treating fluency as evidence

## Done when

There are enough structurally different branches to make evaluation meaningful, or further branches are only surface variations.

Carry forward only the strongest branches, the mechanism each branch uses, and the criterion needed to evaluate them.
